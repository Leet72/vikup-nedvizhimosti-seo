# SEO и поддержка сайта vikup-nedvizhimosti.moscow

Рабочий репозиторий для доработки сайта на WordPress и фиксации изменений.

## Подтверждённая структура
- Сайт: https://vikup-nedvizhimosti.moscow/
- WordPress, пользовательская тема в `wp-content/themes/mvk/`.
- Главная страница сформирована в `index.php` этой темы.
- Блок «Отзывы о нашей работе» расположен примерно в строках 181–209 `index.php`.
- Слайдер отзывов читает `carbon_get_theme_option('nk_feedback_bar')`.
- Под слайдером расположена статическая картинка рейтинга Яндекса `ya_feedback-3.png`; её предстоит заменить официальным бейджем.
- Настройки темы в панели WordPress отображаются пустыми: причину ещё необходимо диагностировать.
- Используются Contact Form 7, интеграция заявок в Telegram, Yoast SEO, WP Statistics.

## Задачи
1. Создать резервную копию **сайта и базы данных** вне публичного репозитория; проверить возможность восстановления.
2. Получить и проверить исходники темы `mvk`; добавить только безопасные файлы.
3. Изучить `functions.php`, определить регистрацию Carbon Fields и причину пустой страницы «Настройки темы».
4. Встроить официальный бейдж Яндекс Бизнеса с актуальным рейтингом, сохранив оформление и мобильную адаптацию.
5. Проверить формы, доставку заявок и аналитику.
6. Провести технический SEO-аудит и обновить замеры позиций по имеющемуся семантическому ядру.

## Безопасность и порядок изменений
- Не коммитить `wp-config.php`, дампы базы данных, секреты, пароли, ключи API, персональные данные, загрузки пользователей и резервные копии.
- Репозиторий **публичный**, пока владелец не изменит видимость.
- Изменения в работающий сайт вносить только после резервного копирования, локальной проверки и подготовки отката.
- Все изменения фиксировать отдельными коммитами.
