# Официальный рейтинг Яндекс Карт — блок отзывов

Дата: 24 октября 2026 г.

## Виджет от владельца организации

```html
<iframe src="https://yandex.ru/sprav/widget/rating-badge/161893440217?type=rating" width="150" height="50" frameborder="0"></iframe>
```

- Организация в Яндекс Бизнесе: `161893440217`.
- Источник отображаемого рейтинга — официальный iframe Яндекса; не задавать рейтинг и число отзывов вручную.
- Место вставки: компонент `wp-content/themes/mvk/template-parts/reviews.php`, внутри `<div class="mvk-reviews__yandex-slot" id="mvk-yandex-rating-slot">...</div>`.
- Для доступности добавить `title="Рейтинг компании на Яндекс Картах"`; границу iframe убрать CSS.
- Контейнер iframe оформить белой карточкой размером не менее 166 × 66 px, чтобы на тёмном фоне блока было читаемо.
- Оставить ссылку «Смотреть все отзывы» на `/otzyvy-o-kompanii-moskovskii-vykup-kvartir/`.
- Существующие отзывы получать через `carbon_get_theme_option('nk_feedback_bar')`, не заменять тестовыми отзывами.
- Не менять URL посадочных страниц, формы и другие блоки темы.

## Состояние

Подготовлен обновлённый локальный пакет фронтенда с iframe вместо заглушки. Код PHP проверен `php -l`. **На рабочем сайте не опубликовано.** Для запуска требуется резервная копия файлов и БД, проверка на тестовом сайте, затем подтверждённый деплой с возможностью отката.

Репозиторий содержит фиксацию решения; готовый локальный ZIP хранился отдельно, без помещения всей WordPress-темы в публичный репозиторий.
