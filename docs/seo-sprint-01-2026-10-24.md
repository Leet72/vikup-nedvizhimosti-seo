## Неделя 1 (24–30 октября) — точечная техническая чистка и два приоритетных URL
1. Зафиксировать в Яндекс Вебмастере актуальную 30-дневную статистику (запросы + страницы), регион Москва, отдельно мобильные/ПК, если доступно.
2. Проверить живой HTML главной и страницы залога: ровно один `<title>`, один canonical, корректный description и H1. В `header.php` присутствует вручную вставленный `<title><?php wp_title(); ?></title>` после `wp_head()`; с Yoast возможен дубль. Не удалять вслепую — проверить исходный HTML и подготовить патч с резервной копией.
3. Проверить `/page/2/` и `/page/3/`: если это действительно копии фиксированной главной без полезной пагинации, согласовать точечные 301 на `/`. **Не** распространять такое правило на категории и статьи.
4. Главная: сохранить нынешний H1 и позиционирование, поправить опечатки, проверить уникальные преимущества и лид-форму. Изменять title только после просмотра фактического поискового сниппета.
5. Страница залога: заменить общий H1 «Квартира в залоге» на «Выкуп квартир в залоге в Москве» после проверки соответствия содержимому; уточнить процедуру, ограничения и порядок согласования с залогодержателем; добавить реальные документы/кейсы без обещаний результата для всех случаев.
6. Яндекс Метрика: измерять именно успешные отправки CF7 и клики по контактам; проверить 1–2 тестовыми заявками.

## Неделя 2 (31 октября–7 ноября) — каннибализация и внутренние ссылки
1. Из XML (162 статьи) проверить 4 пары наибольшего текстового сходства: 481↔690, 535↔536, 467↔654, 486↔531. Проверить канонический URL, индексацию и трафик **до любых 301**.
2. В 133 публикациях замечены `<head>/<title>/<body>` внутри контента и в 135 — `<style>`; на тестовой копии проверить фактическую разметку и только потом подготовить нормализацию.
3. Из релевантных статей поставить осмысленные ссылки на главную и на одну целевую страницу по залогу, избегая повторов анкорных ссылок в каждом абзаце.
4. Добавить реальные кейсы выкупа и информацию о компании только при наличии подтверждённых материалов.

## Приёмка каждой правки
- Есть бэкап файлов и БД и явный способ отката.
- Не меняются URL существующих страниц, если не готов адресный 301.
- HTTP статус без 500/404, формы/квиз действуют, телефон кликабелен, H1 и SEO-метаданные валидны, мобильная версия проверена.
- Изменения зафиксированы отдельным Git коммитом и проверены на тестовой копии.
- Отправить затронутые URL на переобход и наблюдать 2–4 недели.
