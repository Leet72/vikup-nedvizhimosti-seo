# Блок отзывов на главной — только Яндекс Карты

**Текущий вариант:** один H2 «Отзывы о нашей работе», под ним единственный официальный iframe Яндекс Карт 560×800. Никаких прежних карточек отзывов, Owl Carousel, кнопок и повторяющихся описаний.

## Новые файлы темы в этой ветке
- `wp-content/themes/mvk/template-parts/yandex-reviews.php`
- `wp-content/themes/mvk/css/yandex-reviews.css`

Дополнительный JS **не требуется**.

Ссылка на предоставленный владельцем виджет:
`https://yandex.ru/maps-reviews-widget/161893440217?comments`.

Ссылка-атрибуция Яндекс Карт оставлена:
`https://yandex.ru/maps/org/moskovskiy_vykup_kvartir/161893440217/`.

## Как применить к существующей теме

**Сначала создать проверенный полный бэкап файлов и БД** и тестовую копию WordPress. Сравнить исходники с текущими серверными версиями. Не заменять файлы вслепую.

1. Скопировать `yandex-reviews.php` в `wp-content/themes/mvk/template-parts/`, `yandex-reviews.css` в `wp-content/themes/mvk/css/`.
2. В `wp-content/themes/mvk/index.php` найти блок от комментария `<!-- отзывы -->` до комментария `<!-- видео отзывы -->`; заменить только **старую секцию отзывов** на:

```php
<!-- ------------------------------------- отзывы: Яндекс Карты -->
<?php get_template_part('template-parts/yandex-reviews'); ?>
```

3. В `functions.php` добавить функцию регистрации стилей, не заменяя остальной код:

```php
// Стили официального блока отзывов Яндекс Карт (только главная).
function mvk_yandex_reviews_styles() {
    if (is_front_page()) {
        $file = get_template_directory() . '/css/yandex-reviews.css';
        wp_enqueue_style(
            'mvk-yandex-reviews',
            get_template_directory_uri() . '/css/yandex-reviews.css',
            array(),
            file_exists($file) ? (string) filemtime($file) : null
        );
    }
}
add_action('wp_enqueue_scripts', 'mvk_yandex_reviews_styles');
```

4. Проверить `php -l` и вёрстку в тестовой среде: виджет и атрибуция, мобильная ширина, отсутствие горизонтального переполнения, отсутствие старого слайдера и статичной картинки.
5. Проверить, что остальные разделы, формы и SEO-метаданные не изменились; только затем публиковать.

## Что **не** сделано
- WordPress на хостинге не меняли.
- Полный тест реального iframe в браузере с доступом к Яндексу ещё необходим.
- Проблема пустой административной страницы Carbon Fields решается отдельно.

Рядом с H2 не нужно повторять рейтинг, название компании, отзывы или ссылку: всё содержится в официальном iframe; сохранена только обязательная ссылка-атрибуция.
