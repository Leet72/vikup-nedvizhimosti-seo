# История проекта

## 2026-10-24
- Подготовлена и вручную внедрялась новая секция отзывов Яндекс Карт на главной. Утверждён макет «слева бирюзовая панель, справа официальный iframe». Старые вручную написанные отзывы исключены из согласованной версии.

- Проанализирован WordPress XML на 162 опубликованные статьи: группы одинаковых заголовков, сильные сходства и внедрённые HTML-документы в статьях. Выводы — задача #6.
- Полный XML и чувствительные исходники оставлены вне публичного репозитория.
