## Как продолжать работу
1. Делать полный бэкап **файлов + БД** вне GitHub и проверять возможность восстановления.
2. Сравнивать текущую версию сайта с веткой `main` перед развёртыванием (репозиторий пока **не является** зеркалом production).
3. Менять только нужные PHP-секции; не заменять `public_html/index.php`.
4. Фиксировать каждую доработку в отдельном Git-коммите, с целью, затронутыми файлами, проверками и способом отката.
5. Для SEO — сначала проверять индексацию, canonical и поисковые клики, лишь затем объединять дубли и делать 301.
6. Не публиковать секреты, пользовательские экспорты или клиентские данные в публичном репозитории.

Полных файлов темы `css/`, `img/`, `js/`, `inc/` с хостинга нет.
